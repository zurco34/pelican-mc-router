# Pelican MC Router

Automatic Minecraft hostname routing for Pelican using Infrared.

## Features

- Automatic Pelican server discovery
- Supports Vanilla, Forge, Fabric, NeoForge, CurseForge, FTB and more
- Generates Infrared configuration
- Hot reloads Infrared
- REST API
- Web Dashboard
- Docker Compose ready
- Zero manual route configuration
